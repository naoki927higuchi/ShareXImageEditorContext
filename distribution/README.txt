ShareX イメージエディタで開く — Windows 11 モダンメニュー拡張

対象: Windows 11 / Intel・AMD 64bit。ARM版には対応していません。
ShareX本体を事前にインストールしてください。.NETの別途導入は不要です。

インストール
1. ZIPをローカルのフォルダーにすべて展開します。
2. Install.cmd を通常のダブルクリックで実行します。
   「管理者として実行」は不要です。アプリは現在のユーザーに登録されます。
3. ShareXを検出できない場合、ファイル選択画面で ShareX.exe を選びます。
4. 初回のみ証明書登録のためのUAC画面が出ます。管理者の承認が必要です。
5. 画像を右クリックして「ShareXイメージエディタで開く」を選びます。
   出ない場合は一度サインアウトし、サインインしてください。

インストール後、展開した配布フォルダーは移動・削除できます。
MSIXの実体はWindowsが管理する場所に配置されます。
ShareXの場所を変えた場合はInstall.cmdを再実行してください。

削除
Uninstall.cmd を実行するか、Windowsの「インストールされているアプリ」から
ShareX Image Editor をアンインストールしてください。ShareX本体は削除しません。
ShareXパス設定と証明書は再インストール用に残します。
証明書も削除する場合は certlm.msc の「信頼されたユーザー」→「証明書」で
ShareXImageEditorContextを選び、package-info.jsonのCertificateThumbprintと
一致することを確認して削除します。同じ証明書で署名した更新版の利用にも影響します。

証明書について
この配布物は個人利用向けの自己署名です。初回に公開証明書をローカルコンピューターの
TrustedPeopleストアへ登録します。秘密鍵は同梱していません。
開発者モード、SmartScreen、実行ポリシーの永続設定は変更しません。
会社のPCなどで組織ポリシーにより拒否される場合は管理者に相談してください。
証明書期限はpackage-info.jsonを参照してください。期限後の新規導入には再署名が必要です。

既に旧開発版を登録したPC
旧フォルダーの install-modern.ps1 -Uninstall を先に実行してください。
新規PCではこの操作は不要です。

対象画像: png / jpg / jpeg / bmp / gif / tif / tiff / webp / ico
複数選択はすべて対象画像の場合に表示され、各画像をShareXへ渡します。
